# 全臺縣市預報與設定

天氣地區維持必填，接受全臺 22 縣市，包含澎湖、金門與連江。新使用者只需提供縣市，不再詢問行政區。`台中` 等無歧義別名會正規化；`嘉義`、`新竹` 須說明是縣或市，只有行政區、空值或無效名稱不能完成設定。

資料來源統一為氣象署 `F-D0047-089`，以 `LocationName` 指定縣市，保留 3 小時天氣、降雨機率與溫度處理方式。縣市名稱及氣象署代碼集中於 `src/weather_bot/regions.py`；設定不依賴即時氣象 API 是否可用。

正式設定仍須完成引導並明確確認。一般聊天指定其他明確縣市時只查詢該次地點，晨報及主動提醒仍使用正式設定。回覆標示實際縣市，縣市級資料不描述為特定行政區預報。

n8n 沿用單一 workflow，由 `Process Chat Jobs` 與 `Weather Outbox and Memory` 呼叫共用 Python 業務核心。縣市資料不另存於 workflow 或 Code node。Mock transport 使用縣市資料，檢查資料集、查詢縣市及代碼，整合測試經真實 n8n 驗證設定、查詢與晨報。

舊使用者啟動時依已確認縣市更新資料集及縣市代碼；原行政區、聊天、記憶與預報歷史保留。舊行政區待處理天氣工作改為取消，由縣市排程重新建立；舊地區待送訊息仍受地區代碼檢查，不會當作新地點訊息送出。缺少有效縣市的已完成資料退回地區設定。

Python 回歸：`uv run python -m pytest -q`。n8n adapter 隔離測試：`uv run python n8n/tests/test_service.py`。專用實例未占用時啟動 `uv run python n8n/service.py --mock`，再執行 `uv run python n8n/tests/test_workflows.py`；業務 CWA／AI／LINE 都是 mock，不更新正式 LINE webhook。

2026-10-21 引導與提醒閉環驗證：Python 171 項與 15 個子測試通過（含20項設定／通知閉環案例），3 項 live 未啟用；adapter 隔離測試17／17、真實 n8n 引擎的業務 mock 33／33（含22縣市逐一設定與查詢）通過。節點與完整 workflow 驗證均無錯誤或警告。證據為根目錄 `logs/ci/latest.json`，以及 `n8n/logs/service_tests.json`、`n8n/logs/latest.json`、`n8n/logs/verification.json`。縣市擴充時的22縣市唯讀 CWA 驗證另存 `logs/live/counties.json`，未於本輪重跑。

本輪沒有切換正式服務、更新 LINE endpoint、呼叫真實 CWA／AI 或驗證手機收訊；公開 HTTPS、程序故障恢復的舊報告不視為本次重跑結果。測試用專用實例結束後停止，保留資料。
